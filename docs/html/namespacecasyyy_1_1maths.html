◆ casting_policy

enum class casyyy::maths::casting_policy : unsigned char
exportstrong

Numeric conversion strategy, used for handling different types of number conversions.

Note
The default policy is set to strict.
Enumerator
strict 

Require lossless conversion of values.

Allow promotions between signed integers, floating point numbers and unsigned numbers. Allow non-negative integers promoting to unsigned integers.

Note
Convert integers to floating point numbers isn't allowed.
normal 

Conversion that allows some data loss.

Allow integers convert to a floating numbers. Allow narrow casting from a non-negative integer to an unsigned number.

Note
Positive integers are only allowed to be truncated into unsigned numbers.
relaxed 

The output should be a plain numeric value.

Allow all casting except NaN, Inf and empty.
