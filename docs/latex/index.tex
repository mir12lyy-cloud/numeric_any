\begin{quote}
A type-\/erasure-\/based utility class for arithmetic types. Support addition, subtraction, multiplication, division and comparison. \end{quote}
\hypertarget{index_autotoc_md1}{}\doxysection{\texorpdfstring{Features}{Features}}\label{index_autotoc_md1}

\begin{DoxyItemize}
\item Supports any arithmetic type that conforms to the C++ standard, except {\ttfamily char} (which requires an explicit {\ttfamily signed} or {\ttfamily unsigned} qualification).
\item Supports the four arithmetic operations (addition, subtraction, multiplication, division) and comparison operations.
\item Supports simple print/\+output (formatting control is not currently supported).
\item No RTTI, no virtual functions, no exceptions, and {\ttfamily constexpr}-\/friendly.
\item Policy-\/based numeric conversion.
\item Based on C++20/\+23.
\item Header-\/only, provided in both {\ttfamily .ixx} and {\ttfamily .hpp} build variants.
\end{DoxyItemize}\hypertarget{index_autotoc_md2}{}\doxysection{\texorpdfstring{Installation \& Integration}{Installation \& Integration}}\label{index_autotoc_md2}
\hypertarget{index_autotoc_md3}{}\doxysubsection{\texorpdfstring{Environment Requirements}{Environment Requirements}}\label{index_autotoc_md3}

\begin{DoxyItemize}
\item C++ Standard:\+ At least C++20; C++23 is recommended for a better experience.
\item Compiler:\+ At least GCC 13, Clang 17, or MSVC 19.\+30 (Visual Studio 2019 16.\+10) or later.
\item Operating System:\+ Windows /\+ Linux
\item Dependencies:\+ No external dependencies; uses only the C++20 standard library.
\end{DoxyItemize}
